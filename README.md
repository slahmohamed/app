# سوق بلس | SouqPlus POS & Inventory Management System

نظام متكامل لنقاط البيع (POS)، الكاشير، وإدارة المخزون والتسعير الديناميكي المرتبط بالدولار، ومصفوفة الصلاحية (FIFO).

---

## 🚀 المميزات الرئيسية للنظام

1. **لوحة تحكم ذكية (Executive Dashboard)**:
   - مؤشرات لحظية لمبيعات الوردية وأرباح اليوم وتوزيع الدفع (كاش / بنكك).
   - تنبيهات فورية للنواقص والمنتجات قريبة الانتهاء.
   - شريط أحدث الفواتير والعمليات مع إمكانية تصدير نسخة احتياطية (JSON Backup).

2. **تسجيل دخول آمن ومستقل (Manual Authentication)**:
   - تم إيقاف وحذف أزرار الدخول السريع التلقائي بالكامل لضمان دخول كل مستخدم باسمه وكلمة مروره الخاصة.
   - فصل كامل للصلاحيات بين المالك (Admin) والكاشير (Cashier).

3. **نقطة البيع والكاشير (POS & Checkout)**:
   - دعم كامل للباركود عبر الكاميرا أو أجهزة المسح الضوئي (Barcode Scanners).
   - تقسيم المنتجات إلى تصنيفات سهلة وسريعة الوصول.
   - دعم المنتجات بالوحدة أو بالميزان (كيلوجرام).
   - حاسبة فكة وباقي للمبيعات النقدية، ودعم تحويلات بنكك.
   - طباعة فواتير وإرسال الإيصالات عبر واتساب.

4. **التسعير الديناميكي للدولار (Dynamic Currency Pricing)**:
   - ربط مباشر بين تكلفة الاستيراد بالدولار وسعر البيع بالجنيه السوداني (ج.س).
   - تحديث لحظي لأسعار كافة المنتجات بمجرد تعديل سعر صرف الدولار.

5. **مصفوفة الصلاحية وإدارة التوالف (FIFO Matrix)**:
   - تتبع التشغيلات ودفعات التوريد وتواريخ انتهاء الصلاحية.
   - الخصم التلقائي من الدفعة الأقدم انتهاءً أولاً لمنع التوالف.

6. **إغلاق الورديات وتقارير Z (Shifts & Reconciliation)**:
   - مطابقة الدرج النقدي ومبالغ بنكك.
   - حساب صافي أرباح الوردية (محصورة للمالك فقط).

## 🌐 النشر والاستضافة المجانية على GitHub Pages

النظام مبني كـ تطبيق ويب مستقل (Static Client-Side PWA)، ولا يتطلب أي خادم خلفي معقد (Serverless)، مما يجعله مثالياً للاستضافة المجانية مدى الحياة على **GitHub Pages**:

### خطوات التفعيل لأول مرة:
1. أنشئ مستودعاً جديداً (New Repository) على حسابك في GitHub.
2. افتح موجه الأوامر في مجلد المشروع ونفذ:
   ```bash
   git remote set-url origin https://github.com/USERNAME/REPO_NAME.git
   git add .
   git commit -m "Initial commit"
   git push -u origin main
   ```
3. ادخل على صفحة المستودع على GitHub واذهب إلى:
   - **Settings** -> **Pages**
   - تحت قسم **Build and deployment**:
     - المصدر (Source): **Deploy from a branch**
     - الفرع (Branch): اختر **main** والمجلد **/ (root)**
     - اضغط **Save**
4. خلال دقيقة سيظهر رابط موقعك المجاني:
   `https://USERNAME.github.io/REPO_NAME/`

### لرفع وتحديث النظام في أي وقت:
- ببساطة اضغط نقرتين على ملف `deploy.bat` وسيقوم برفع التحديثات تلقائياً إلى GitHub!
